# ⚔️ War Game - Tower Defense

A browser-based tower defense war game built with vanilla JavaScript and HTML5 Canvas.

## 🎮 How to Play
1. Choose a tower type (Gunner, Sniper, Cannon)
2. Click on the green map (not on the path) to place towers
3. Click **Start Wave** to send enemies
4. Defend your base — don't let enemies reach the end!
5. Earn money by killing enemies and build more towers

## 🏗️ Towers
| Tower | Cost | Damage | Range | Special |
|-------|------|--------|-------|---------|
| 🔫 Gunner | 50 | 10 | 100 | Fast fire |
| 🎯 Sniper | 100 | 30 | 220 | Long range |
| 💥 Cannon | 150 | 25 | 130 | Splash damage |

## 🚀 Deploy on GitHub Pages
1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Source: `main` branch, `/root`
4. Your game is live at `https://yourusername.github.io/war-game/`

## 🛠️ Tech Stack
- HTML5 Canvas
- Vanilla JavaScript (no dependencies)
- CSS3
